## 🚀 About Me

I'm a passionate **Full Stack Developer** from Argentina, based in Denmark and working in **e-mobility**. Most of my days are spent on the software that moves an EV charger from a webshop order to a working installation on someone's wall — order management, installer tooling, and the integrations that tie them together.

### 🎯 What I'm Currently Up To

Currently, I’m working as a **Full Stack Developer at [Nordic Charge](https://nordiccharge.com/)** ⚡, an e-mobility operations platform that brings the entire **CPO (Charge Point Operator) business** together in one place. Nordic Charge manages everything from **logistics, installation, integration, support, and hardware**, making EV charging operations smooth and scalable.

### 💼 Professional Focus

At **Nordic Charge** I work across the whole stack — web platform, mobile and backend services:

- **Partner Portal** — a multi-tenant EV-charging business platform (OMS, field ops, returns, invoicing) built with **Laravel 12, Filament 3 and the TALL stack**, with pipeline-based order management, serialized charger tracking and public order-tracking links
- **Company website** — lead on the new site with **Astro 5, React 19, TypeScript & Tailwind CSS 4**
- **Integrations** — CPO and backend providers (**Monta**, **Zaptec**, **Easee**, **EOSVolt**), webhook intake from **Shopify** and **WooCommerce**, plus logistics, CRM and support tools
- **Installer mobile app** — **React Native / Expo** app for technicians: QR & barcode scanning, serial validation and a step-by-step installation guide, shipped to iOS and Android via EAS
- **WordPress/WooCommerce plugin** — connects merchant stores to the Nordic Charge Partner API, built on **PHP 8.1+** with PHPStan level 8, PHPUnit unit + integration suites and HPOS support
- Throughout: **performance, scalability, testing discipline & modern UI/UX**

> Most of this work lives in private company repositories, so it won't show up in the contribution graph below.
